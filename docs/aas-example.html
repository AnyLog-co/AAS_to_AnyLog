Shells in the AAS

Download and run the Eclipse BaSyx container. It listens on http://127.0.0.1:8081.

docker pull eclipsebasyx/aas-environment:2.0.0-SNAPSHOT
docker run -d --name aas-env -p 8081:8081 eclipsebasyx/aas-environment:2.0.0-SNAPSHOT

Two GET calls. The id in the second path is the submodel id as base64url, with the padding removed. This one is chem:company:hierarchy.

GET http://127.0.0.1:8081/shells
GET http://127.0.0.1:8081/submodels/Y2hlbTpjb21wYW55OmhpZXJhcmNoeQ

A shell contains submodels. A submodel contains properties.

What we have done with DNP3 can be done with Modbus.
The table is modbus_ecm1420.
Possible config. 40089 is holding register offset 88.

run plc client where type = modbus and
  hostname = 192.168.99.159 and
  port = 502 and
  device_id = 1 and
  frequency = 5 and
  name = modbus_ecm1420 and
  dbms = env_sensor and
  table = modbus_ecm1420 and
  map = [
    {"name":"voltage_l1","register":0},
    {"name":"current_l1","register":1},

  ]
